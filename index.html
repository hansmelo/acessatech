🧠 Recursos para diferentes necessidades

Cada estudante aprende de um jeito. Veja quais recursos podem ajudar e ative tudo com um toque.

🧩 Estudantes autistas

  • Modo de leitura tranquilo, com cores suaves
  • Menos elementos na tela
  • Rotina previsível com o temporizador

⚡ Estudantes com TDAH

  • Estudo em blocos curtos de 15 minutos
  • Palavras importantes destacadas
  • Resumos em linguagem simples

👁️ Estudantes com deficiência visual

  • Letras maiores
  • Alto contraste
  • Texto lido em voz alta

📖 Dificuldades de leitura

  • Linguagem simplificada
  • Mais espaço entre as linhas
  • Ouvir enquanto lê
